# Bot Universe

A live star map of practice trading bots that trade **fake money** (Alpaca paper trading).
A learning project, not investment advice.

- `public/` is the website. Its contents are copied to the `gh-pages` branch, the only thing GitHub Pages serves.
- The `data` branch holds `data.json`, updated every few minutes by the bots' computer.
- Live crypto prices load from Coinbase's public API in the viewer's browser.
